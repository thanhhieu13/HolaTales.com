# Frontend security verification — 2026-10-15

Status: mitigated paths, upstream Vue 2/Vuetify 2 risk remains. No zero-advisory claim.

`npm ci` and production build succeeded. Audit reduced from 50 packages (17 high) to **4 packages (1 high, 3 low)**. npm counts affected packages, not distinct vulnerabilities. Evidence: `qa-results/rc2-npm-before.json`, `rc2-npm-final.json`, `rc2-npm-ci.log`, `rc2-build-final.log`.

| Group | Exploit prerequisite / observed path | Action and residual risk |
|---|---|---|
| Legacy Mix, BrowserSync, dev middleware, older Axios/Webpack/loader chains | Development server or build-time input. No need for these public server features in this app. | Removed Mix/BrowserSync and old compiler packages. Direct Webpack production assets preserve Laravel mix manifest. No dev HTTP server or buildHttp configured. Audit no longer reports these groups. |
| PostCSS arbitrary source-map read, stringify injection, parsing; selector CPU exhaustion | Attacker-controlled CSS compiled on build server, sourceMappingURL auto-loading, or output embedded into HTML style. Learner imports contain text, never compile CSS. | Scoped compiler-utils overrides use PostCSS 8.5.30 / selector-parser 7.1.6. Clean npm ci resolves both; production scoped-style build succeeds. No reported PostCSS advisories remain. |
| Vue parseHTML ReDoS; dependent vuex/circle-progress (3 low affected packages) | Untrusted HTML passed to Vue runtime template compiler. | Webpack aliases Vue runtime-only; root Layout uses precompiled render. Bootstrap JSON is HEX escaped; no server template compilation. UserManual Markdown is sanitized with DOMPurify. Vue 2 is still upstream affected/EOL; this is path mitigation, not a patched Vue version. [Advisory](https://github.com/advisories/GHSA-5j4c-8p2g-v4jx). |
| Vuetify prototype pollution (remaining high) | Untrusted objects merged into component/theme options with prototype keys. | Bootstrap and every JSON Axios success response recursively remove __proto__/constructor/prototype; configuration options are static and learner text renders as text. Executable frontend test supplies nested malicious JSON and asserts no prototype pollution. Residual: third-party/internally generated objects bypassing this boundary need ongoing review. No upstream 2.x patch installed. [Advisory](https://github.com/advisories/GHSA-3jp5-5f8r-q2wg). |
| Vuetify VDatePicker XSS (reported within same high package) | Attacker controls title-date-format output inserted as HTML. | Removed VDatePicker usage from Calendar; native month input. No active app callback/path to that sink found. Package still contains component code. [Advisory](https://github.com/advisories/GHSA-9w3x-85mw-4fwm). |

Frontend executable tests cover JSON sanitization, runtime-only bootstrap constraints, 419/network/restored events, and interface locale independence. Build emits 12 legacy scoped-style export warnings; not treated as an audit fix or a clean build claim. Browser reader/import rendered successfully. CI retains strict npm audit failure so remaining upstream alerts cannot silently become a green security gate. Migration to maintained Vue/Vuetify requires a separate compatibility increment; no forced major upgrade here.
